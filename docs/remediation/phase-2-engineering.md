## 2. Architecture after Phase 2

```
main ──► cmd (urfave/cli flags → app calls, exit codes)
          └► app (workflows; injected Stdin/Stdout/Stderr, Prompter, ssh options)
               ├► vault   (format v2/v1, locking, atomic writes, path safety, backup)
               ├► sshutil (validation, key import, read-only agent, ssh/sendkey runner)
               ├► keygen  (ed25519 / RSA, OpenSSH format)
               └► model   (Entry, pure helpers)
```

No new third-party dependencies. `golang.org/x/sys` moved from indirect to direct (flock, LockFileEx, prctl).
